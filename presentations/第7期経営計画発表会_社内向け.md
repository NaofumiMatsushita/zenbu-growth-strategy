## 2. 第6期の成果と課題

### 2.1 成果（✅できたこと）

#### ① 事業の継続と安定化
- 12ヶ月連続で月商1,100万円超を達成
- 売上の下限が安定（9月以降も月1,100万円以上維持）
- 騒音測定サービスの認知度向上

#### ② 限界利益率の維持
- 限界利益率: **37.2%**（目標35%以上を達成）
- 売上原価率: 62.8%（適正水準）
- 業務委託費・出動費のコントロール成功

#### ③ 後半期の利益改善
- 5月の大幅赤字（-1,520万円）からの回復
- 6月以降は概ね黒字基調（9月除く）
- 1-3月は安定して200万円超の営業利益

### 2.2 課題（❌できなかったこと）

#### ① 売上目標の大幅未達

```
計画: 215,393,000円
実績: 159,145,741円
━━━━━━━━━━━━━━━━━━
未達: -56,247,259円 (-26.1%)
```

**要因:**
- 9月以降の売上失速（計画比60%前後）
- 季節性への対応不足
- 営業力の不足

#### ② 5月の役員報酬支出による大幅赤字

```
5月実績:
- 役員報酬: 18,100,000円（異常値）
- 営業利益: -15,204,383円
```

**影響:**
- 年間営業利益を大きく押し下げ
- キャッシュフローへの影響

#### ③ 人件費の計画乖離

```
計画: 21,261,000円
実績: 19,880,483円
━━━━━━━━━━━━━━━━━
差異: -1,380,517円
```

- 採用計画の遅れ
- 組織体制強化の遅延

#### ④ 営業利益の赤字転落

```
計画: +13,141,588円（黒字）
実績:  -1,898,976円（赤字）
━━━━━━━━━━━━━━━━━━
差異: -15,040,564円
```

### 10.2 用語集

| 用語 | 説明 |
|------|------|
| **限界利益** | 売上高から変動費（売上原価）を差し引いた利益 |
| **限界利益率** | 限界利益 ÷ 売上高 × 100 |
| **営業利益** | 限界利益から固定費（人件費・販管費）を差し引いた利益 |
| **営業利益率** | 営業利益 ÷ 売上高 × 100 |
| **CV率** | コンバージョン率。問い合わせから成約に至る割合 |
| **LTV** | Life Time Value。顧客生涯価値 |
| **CAC** | Customer Acquisition Cost。顧客獲得コスト |
| **MRR** | Monthly Recurring Revenue。月次経常収益 |
| **KPI** | Key Performance Indicator。重要業績評価指標 |
| **PDCA** | Plan-Do-Check-Act。計画-実行-評価-改善のサイクル |
