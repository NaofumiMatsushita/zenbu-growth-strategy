# HYROX サブ2時間 トレーニングプラン
### 対象: 45歳男性 / Men's Open シングル / 大阪 2027年1月・名古屋 2027年4月

作成日: 2026年8月30日
作成期間: 2026年9月 〜 2027年4月（全33週）

---

## 0. 前提条件（要確認）

このプランは以下を前提に組んでいます。異なる場合は該当箇所を調整してください。

| 項目 | 前提 | 備考 |
|---|---|---|
| 区分 | Men's Open（シングル） | Pro / Doubles の場合は重量・戦略が変わる |
| エイジ | 45-49 | 回復サイクルを3週ビルド+1週回復で設計 |
| 目標 | 総合 2:00:00 切り（計画上のターゲットは **1:56:00**） | 4分のバッファを持つ |
| 練習頻度 | 週4日（＋任意で軽い1日） | 週3日版も §6 に記載 |
| 現状走力 | **未確認 → Week 1のテストで判定** | §3 で分岐 |
| 器具 | SkiErg/ローワー/そり が無い前提でも回る代替を用意 | §9 |

> **重要（安全面）**: 45歳で高強度の心肺負荷をかける前に、健康診断・できれば運動負荷心電図を受けてください。胸痛・異常な息切れ・めまいがあれば即中止して受診。これはプランの一部として最優先事項です。

## 1. HYROXの競技構造とサブ2の意味

**構成**: 1kmラン × 8本 と ワークステーション × 8種を交互に実施（合計 8km走 + 8種目 + ロクスゾーン移動）

```
Run 1km → ① SkiErg 1000m
Run 1km → ② Sled Push 50m（Open 152kg）
Run 1km → ③ Sled Pull 50m（Open 103kg）
Run 1km → ④ Burpee Broad Jump 80m
Run 1km → ⑤ Row 1000m
Run 1km → ⑥ Farmers Carry 200m（2×24kg）
Run 1km → ⑦ Sandbag Lunges 100m（20kg）
Run 1km → ⑧ Wall Balls 100回（6kg / 3.05m）
```

**サブ2の位置づけ**: Men's Open では「しっかり準備した市民アスリートの現実的な第一目標」。才能ではなく**設計と積み上げで届くライン**です。逆に言えば、行き当たりばったりの練習では届きません。

## 2. サブ2の分解 — タイム配分表（ターゲット 1:56:00）

サブ2の本質は「速く走ること」ではなく **「8kmを7分/km前後で刻み続けられる状態を、8種目の疲労下で維持すること」** です。

### 2-2. ステーション別ターゲット

| # | 種目 | ターゲット | 難易度 | メモ |

## 3. Week 1: ベンチマークテスト（最重要）

初週で現在地を測ります。ここの結果でプランの入口が決まります。**測らずに始めないでください。**

### 3-1. テストメニュー（2日に分割）

**Day A（テスト①）**
1. ウォームアップ 15分
2. **5km タイムトライアル**（フラットな周回コース or トレッドミル1%傾斜）
3. 完全休息 10分
4. **1000m ローイング 全力**

**Day B（テスト②、Day Aから中2日空ける）**
1. ウォームアップ 15分
2. **Wall Ball（6kg / 3.05m）50回 タイム計測** ＋ 最大連続回数
3. 休息 5分
4. **Burpee Broad Jump 40m タイム計測**
5. 休息 5分
6. **サンドバッグ（20kg）ランジ 最大連続距離**
7. 休息 5分
8. **ダンベル24kg×2 ファーマーズキャリー 最大連続距離**

### 3-2. 判定基準

| 指標 | サブ2 射程圏 | 要強化 | 大幅に不足 |
|---|---|---|---|
| 5km TT | 26分以内 | 26-30分 | 30分超 |
| Row 1000m | 3:50以内 | 3:50-4:20 | 4:20超 |
| Wall Ball 50回 | 5:00以内 | 5:00-7:00 | 7:00超 |
| WB 最大連続 | 25回以上 | 15-24回 | 15回未満 |
| BBJ 40m | 3:30以内 | 3:30-4:30 | 4:30超 |
| SBランジ連続 | 50m以上 | 25-49m | 25m未満 |
| FC 連続 | 200m（無停止） | 100-199m | 100m未満 |

### 3-3. 判定に応じた分岐

- **大半が「射程圏」** → 本プランをそのまま実行。大阪でサブ2、名古屋で1:50切りを狙う
- **大半が「要強化」** → **これが標準的な出発点です。** 本プランどおりで大阪サブ2は十分現実的
- **「大幅に不足」が3つ以上** → Phase 0 を4週→8週に延長し、**大阪は完走＋データ取り（目標2:15前後）、名古屋でサブ2**に目標を再配置。20週で無理に詰め込むと故障して両方失います
- **走る習慣がゼロ（5km完走が困難）** → 最初の6週は走る土台づくりのみに充てる（§6-4）

## 6. フェーズ別メニュー詳細

### 6-1. Phase 0（Week 1-4）— 基礎・評価

**目的**: 走れる体をつくる。フォームと腱の耐性。テストで現在地を確定。

- **火**: イージーラン 4-5km ＋ ステーション技術練習（正しいフォームの習得優先、速度不問）
  - Wall Ball: 10回×5セット（深さと高さを妥協しない）
  - Burpee Broad Jump: 10m×4本
- **水（筋力A）**:
  - スクワット 5×8（フォーム重視、中重量）
  - ルーマニアンデッドリフト 4×10
  - ウォーキングランジ 3×20歩
  - シーテッドロー 4×12
  - **カーフレイズ 3×20（片脚）** ← アキレス腱保険。必須
- **金（筋力B）**:
  - ダンベルショルダープレス 4×10
  - ラットプルダウン / 懸垂 4×8-10
  - プランク 3×60秒 / サイドプランク 3×40秒
  - **ファーマーズホールド 4×60秒（できる最大重量）** ← 握力
- **土**: ロング走 40-60分（Zone 2、会話できるペース）

**週間目標**: 走行 15→25km / 筋力2回 / 完全休養は必ず取る

### 6-2. Phase 1（Week 5-10）— ビルド

**目的**: 有酸素の器を広げる。筋持久力をつける。全ステーションを「できる」状態にする。

- **火（キー①）**: コンプロマイズド・インターバル
  ```
  4-5セット:
    1km ラン @ 6:40-6:50/km
    → 即座にステーション1種（下記から日替わり）
    → 90秒レスト
  ステーション: SkiErg 250m / Row 250m / WB 25回 / BBJ 20m / SBランジ 25m
  ```
- **水（筋力A）**: Phase 0 と同構成、重量を漸増（+2.5-5kg/週）
  - ＋ **そり押し 20m×6本**（無ければ §9 の代替）
- **金（筋力B）**: Phase 0 と同構成
  - ＋ **Wall Ball 累積 150回**（20-25回×6-8セット、セット間60秒）
- **土（キー②）**: 隔週で切り替え
  - **奇数週**: ロング走 8-12km（Zone 2、一定ペース）
  - **偶数週**: **クォーター・ハイロックス**
    ```
    2km ラン → SkiErg 500m → 1km ラン → そり押し 25m
    → 1km ラン → BBJ 40m → 1km ラン → WB 50回
    ```

**Phase 1 終了時のチェックポイント（Week 10）**
- 10km を 65分以内でノンストップ
- Wall Ball 連続 30回
- クォーター・ハイロックスを止まらず完走

---

### 6-3. Phase 2（Week 11-16）— 専門期【最重要フェーズ】

**目的**: 「疲労した脚で走る」能力の獲得。ここがサブ2の本体です。

- **火（キー①）**: ハイロックス・ペースインターバル
  ```
  6セット:
    1km ラン @ 6:45/km（レースペース厳守）
    → ステーション1種を**レース強度**で
    → レスト60秒のみ
  ```
  ※ 後半のセットでペースが落ちなくなったら、狙いどおり適応しています

- **水（筋力A）**: 出力維持しつつ量を減らす（4×6程度）＋ そり押し/引き を必ず入れる
- **金（筋力B）**: **ウィークポイント集中日**
  - Week 1テストで最も悪かった種目を単独で叩く
  - Wall Ball が弱い → 累積200回
  - ランジが弱い → 荷重ランジ 累積200m
  - 握力が弱い → ファーマーズ 累積600m
- **土（キー②）**: 隔週
  - **奇数週**: ロング走 12-14km、後半5kmをレースペースに上げる（プログレッシブ）
  - **偶数週**: **ハーフ・ハイロックス**（4kmラン + 前半4種目 or 後半4種目）
    - Week 12: 前半4種目版（Ski / Push / Pull / BBJ）
    - Week 14: **後半4種目版（Row / FC / ランジ / WB）** ← 精神的に一番きつい。ここを経験しておく
    - Week 16: 前半4種目版で、Week 12 のタイムを上回る

**Phase 2 終了時のチェックポイント（Week 16）**
- ハーフ・ハイロックスを 55分以内
- 6本目の1kmを 7:00/km 以内で維持

## 7. 8ステーション攻略ポイント

| 種目 | 落とし穴 | 対策 |
|---|---|---|
| **① SkiErg** | 脚のドライブを使いすぎて、後の走りに響く | 上体の前傾と体幹の折りたたみで引く。脚は添えるだけ。ダンパー 5-6 |
| **② Sled Push** | 立ち姿勢で押す → 全く進まない | 腕を伸ばし切り、体を一直線に低く。歩幅は小さく回転を速く。止まると再始動が地獄なので**止まらない** |
| **③ Sled Pull** | 腕で引いて背中と握力を消耗 | 体重を後ろに預けて座り込むように。ロープを手繰る腕は伸ばしたまま、脚で下がる |
| **④ Burpee Broad Jump** | 序盤の勢いで飛ばして心拍が振り切れる | **1回ごとに一定のリズム**。跳躍距離は欲張らず、腕立ての深さだけ確保。呼吸を数える |
| **⑤ Row** | レートを上げて心拍だけ上がる | 24-26spm、1本を強く長く。脚→体幹→腕の順を守る。ダンパー 4-5 |
| **⑥ Farmers Carry** | ここで休もうとして逆に遅くなる | **走る**。実質ボーナス区間。握力は事前トレで作っておく |
| **⑦ Sandbag Lunges** | 100mを想像より長く感じて心が折れる | **事前に分割を決める**（例: 25m×4）。バッグは首の後ろで安定。膝が内に入らないように |
| **⑧ Wall Balls** | 序盤に30回連続 → その後5回ずつしか出来なくなる | **最初から分割する**。推奨: 15-15-10-10-10-10-10-10-10。セット間は10秒固定。深く座り、腕で投げず脚の伸展で放る |

**ロクスゾーン（移動）**: 8回合計で9分。ここを歩くと簡単に3-4分失います。**ジョグで移動**。給水は前半2回・後半2回に限定して、都度の立ち止まりをなくす。

## 8. レース当日の戦略

### 8-1. タイムライン
- **-3時間**: 食事（消化の良い炭水化物 中心、脂質は避ける）。例: おにぎり2個＋バナナ
- **-90分**: 水分 500ml をこまめに
- **-60分**: カフェイン 100-200mg（普段から試している人のみ。本番初投入は厳禁）
- **-40分**: ウォームアップ開始 — ジョグ10分 → 動的ストレッチ → WB 10回 → BBJ 5回 → 短いダッシュ3本
- **-10分**: 呼吸を整える。Run 1 のペースを口に出して確認

### 8-2. 3つの鉄則
1. **Run 1 は 6:20/km。周りに絶対ついていかない。** 最初の1kmで貯めた30秒は、後半で3分になって返ってきます
2. **④バーピーブロードジャンプが終わった時点で、まだ余裕があること。** ここで限界なら、目標を1:59:59から「完走」に切り替えて後半を守る
3. **⑧ウォールボールは最初から分割。** 「今日は調子がいい」と感じても計画どおりに割る

### 8-3. 中間チェックポイント（サブ2ペース）
| 通過点 | 目標経過時間 |
|---|---|
| ② Sled Push 終了 | 約 27:00 |
| ④ BBJ 終了 | 約 55:00 |
| ⑥ Farmers Carry 終了 | 約 1:20:00 |
| ⑧ Wall Ball 開始時 | 約 1:41:00 |

⑧開始時点で **1:45:00 を超えていたらサブ2は厳しい**。その場合はウォールボールを守りに行き、確実にフィニッシュ（次戦のデータにする）。

## 9. 器具がない場合の代替

日本のジムには SkiErg・そり・サンドバッグが無いことが多いので、代替を用意します。**「代替でも8割は作れる」** が結論です。

| 本番種目 | 代替 |
|---|---|
| **SkiErg** | ローイングマシン ＋ ケーブル・ストレートアームプルダウン（4×20）／ バンド・オーバーヘッドプル |
| **Sled Push** | ①トレッドミル電源OFFでの手押し（可能な機種のみ）②傾斜15% 早歩き 3分×5 ③レッグプレス 20回×5（短休息）④プレートを床で押す（滑る床＋タオル） |
| **Sled Pull** | 重量プレートにロープを結んで引く／ シーテッドロー高重量 8×5／ バンド・ローイング後退 |
| **Row 1000m** | そのまま（大半のジムにあり） |
| **Burpee Broad Jump** | 器具不要。そのまま実施 |
| **Farmers Carry** | ダンベル/ケトルベル 24kg×2。無ければ20kg×2で距離を1.2倍 |
| **Sandbag Lunges** | バーベル・バックランジ／ リュックに水袋・本を詰めて20kg |
| **Wall Balls** | メディシンボール 6kg ＋ 壁に3.05mの目印（テープ）／ 無ければダンベル・スラスター 2×10kg × 回数1.2倍 |

## 10. 45歳としての管理項目（ここが勝負の分かれ目）

若い選手との差はトレーニング内容ではなく**回復とリスク管理**に出ます。

### 10-1. 回復
- **睡眠 7-8時間を最優先**。睡眠を削って練習するのは、貯金を切り崩して投資するのと同じで純損失です
- 「3週ビルド + 1週回復」を絶対に守る。調子が良い週ほど守る
- 安静時心拍が普段より+7bpm以上の朝は、その日の高強度を中止して軽い有酸素に振り替える

### 10-2. 栄養
- **たんぱく質: 体重×1.6-2.0g/日**（体重70kgなら 112-140g）。加齢で合成効率が落ちるため、若い頃より多く必要
- 練習後30-60分以内に たんぱく質25-40g ＋ 炭水化物
- 練習日は炭水化物を削らない（減量とサブ2を同時に狙わない）
- ビタミンD・鉄・マグネシウムは健診値を確認

### 10-3. 故障予防（毎回のルーティンに組み込む）
| 部位 | リスク | 予防種目 |
|---|---|---|
| アキレス腱 | 走行量増加期に断裂・炎症 | 片脚カーフレイズ 3×20（週2、休まず継続） |
| ハムストリング | 高強度ラン中の肉離れ | ノルディックハムカール 3×5、RDL |
| 膝（ランジ・WB） | 膝蓋腱炎 | ステップダウン 3×10、殿筋強化（ヒップスラスト） |
| 腰（そり引き・SB） | 腰痛 | デッドバグ、バードドッグ、体幹の恒常的強化 |
| 肩（WB・Ski） | インピンジメント | フェイスプル 3×15、肩甲帯モビリティ |

**中止基準**: 鋭い痛み・翌日も残る関節痛・左右差のある腫れ → 練習を止めて整形外科へ。2週の休養は取り返せますが、腱断裂は8ヶ月です。

## 11. 大阪 → 名古屋の13週

大阪はゴールであると同時に、**名古屋のための最良のデータ収集機会**です。

### Step 1: 大阪直後（レース当日〜翌日）に必ず記録
- 全8種目のスプリットタイム（公式リザルトで取得可能）
- 各ランの実測ペース（GPSウォッチ）
- **崩壊した地点と、その時の主観**（脚か、心肺か、握力か、精神か）

### Step 2: 回復期（2週）
- 1週目: 完全休養 or ウォーキングのみ
- 2週目: 軽いジョグ 30分×2、モビリティ

### Step 3: 再構築期（5週）
大阪のデータから**最も時間を失った2種目のみ**に絞って集中強化。全部やろうとしないこと。

| 大阪での症状 | 名古屋への処方 |
|---|---|
| ランが7:30/km超に落ちた | 有酸素ベース増（週走行距離+20%）、閾値走を週1追加 |
| Wall Ballで10分以上 | WB累積 週300回、フロントスクワット強化 |
| そりで止まった | 脚の絶対筋力（スクワット・レッグプレス）を重量ベースで伸ばす |
| Farmers Carryで落とした | 握力集中（デッドハング、ファーマーズホールド、太いグリップ） |
| ランジで大幅ロス | 荷重ランジ 週300m、片脚バランス強化 |

### Step 4: 専門期（4週）＋ 調整（2週）
Phase 2/3 と同構成、ただしペース設定を **1:50:00 ターゲット**（ラン平均 6:30/km）に引き上げ。

**名古屋の目標: 1:50:00 切り**（大阪でサブ2達成の場合）／ **サブ2達成**（大阪で未達の場合）

## 13. まとめ — サブ2の3本柱

1. **走力**: 8kmを平均7:00/kmで、疲労下でも刻める有酸素能力
   → Phase 1 の Zone 2 ロング走と Phase 2 のコンプロマイズドランで作る
2. **筋持久力**: Wall Ball 100回・ランジ100m・BBJ 80m を「止まらずに」続けられる耐性
   → 週2回の筋力トレと累積ボリュームで作る
3. **ペース管理**: Run 1 を我慢し、Wall Ball を最初から分割する規律
   → シミュレーションで体に覚え込ませる

**最大のリスクは故障です。** 45歳のプランでは、練習を1回増やすことより1回きちんと休むことのほうが、多くの場合サブ2に近づきます。
